# Overleaf Writing Support

This folder is used to bridge experiment outputs and manuscript writing.

## Files
- `weekly_writing_board.md`: Weekly writing TODO and section progress
- `figure_table_manifest.md`: Figure/table source mapping and status

## Suggested Use
1. After each weekly training wrap-up, update `weekly_writing_board.md`
2. Register new figures/tables in `figure_table_manifest.md`
3. Keep manuscript claims linked to explicit experiment/result paths
