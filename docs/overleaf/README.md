# Overleaf Writing Support

This folder is used only for paper drafting support.

## Files
- `weekly_writing_board.md`: Paper writing board (sections/owners/sources)
- `figure_table_manifest.md`: Figure/table source mapping and status

## Suggested Use
1. Use Notion weekly page for weekly TODO and meeting-week report.
2. Use this folder only for paper manuscript content planning and traceability.
3. Register new figures/tables in `figure_table_manifest.md`.
4. Keep manuscript claims linked to explicit experiment/result paths.
