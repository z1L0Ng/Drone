\section{Conclusion}

This draft positions the project as an onboard voice safety layer for small drones operating under rotor-like self-noise. The current paper should be anchored on the reproducible \texttt{w14/preprocess\_ext} evidence: it is the strongest stable noisy-set result in the allowed paths and gives the clearest basis for the emergency-aware intent-recognition story.

The deployment story should remain deliberately conservative. The ESP32/TFLM artifacts show concrete memory and operator constraints, and the \texttt{xiao\_bottleneck256\_tflm} branch is the current compatibility-oriented candidate. That branch is still converging: it is useful evidence for the embedded path, but not yet a completed onboard result. The next milestone is to close the board-side gate with successful allocation, successful invocation, printed labels, and then latency and real-world protocol measurements.
